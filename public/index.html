About the project

Built for practical home cooking.

What’sInMyKitchen helps students and home cooks discover recipes from ingredients they already have. The matching logic compares required ingredients against your pantry and shows exactly what is missing.

The app uses a Java HTTP server and MySQL database, with a responsive frontend that feels polished on mobile, tablet, and desktop.

How the matching algorithm works

Each recipe calculates a required-ingredient match by dividing matched required ingredients by total required ingredients.

Optional ingredients do not increase the percentage and are shown separately as extras to consider.
